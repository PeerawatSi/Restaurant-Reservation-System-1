# 🍽️ Restaurant Reservation System

## 📖 Project Overview
The **BOOkaBle** is a web-based application designed to manage restaurant bookings efficiently. It allows customers to make table reservations online and enables restaurant staff to view, manage, and update reservation data through an intuitive interface.
